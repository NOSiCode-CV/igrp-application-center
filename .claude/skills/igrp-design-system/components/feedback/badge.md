# IGRPBadge

## Import

```tsx
import { IGRPBadge, igrpBadgeVariants } from '@igrp/igrp-framework-react-design-system';
```

## Props

`variant` (default, secondary, outline), `color` (primary, secondary, success, destructive, warning, info, indigo), `dot`, `children`.

## Example

```tsx
<IGRPBadge color="success">Active</IGRPBadge>
<IGRPBadge color="destructive">Inactive</IGRPBadge>
```
